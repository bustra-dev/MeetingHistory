# 会議記録アプリ（Googleスプレッドシート保存版）

1つのHTMLファイルだけで動くWebアプリです。データは自分のGoogleドライブにあるスプレッドシートに保存されるので、Windows PC と iPad のどちらからでも同じデータを使えます。サーバーの構築は不要で、静的ホスティング（GitHub Pages など）に置くだけで使えます。

---

## 1. Google Cloud の準備（最初の1回だけ）

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作ります（例：`meeting-log`）。
2. 「APIとサービス」→「ライブラリ」で、次の2つを**有効**にします。
   - Google Sheets API
   - Google Drive API
3. 「APIとサービス」→「OAuth 同意画面」（Google Auth Platform）で次のように設定します。
   - ユーザーの種類：**外部**
   - アプリ名・サポートメール：自分のもので可
   - スコープ：`.../auth/drive.file` を追加
   - テストユーザー：**自分のGoogleアカウント**を追加
   - 公開ステータスは「テスト」のままで構いません。自分用なら審査は不要です。
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」で次のように設定します。
   - 種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：アプリを置くURLの**ドメインまで**を入れます。
     - GitHub Pages の例：`https://<GitHubユーザー名>.github.io`
     - 手元で試す場合：`http://localhost:8000`
   - リダイレクトURIは不要です。
5. 表示された**クライアントID**（`xxxx.apps.googleusercontent.com`）を控えます。

## 2. クライアントIDを設定する

`index.html` の次の部分を書き換えます。

```js
const CONFIG = {
  CLIENT_ID: 'YOUR_CLIENT_ID.apps.googleusercontent.com',  // ← ここ
  SHEET_TITLE: '会議記録DB'
};
```

クライアントIDは秘密情報ではないので、公開リポジトリに置いても問題ありません。

## 3. 置き場所（GitHub Pages の例）

1. GitHub で新しいリポジトリを作り、`index.html` をアップロードします。
2. リポジトリの「Settings」→「Pages」→「Branch: main / root」を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

手元で試すだけなら、フォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。ファイルをダブルクリックで直接開く方法ではログインできません。

## 4. 使い方

- PC でも iPad（Safari）でも同じURLを開き、「Googleでログイン」を押します。
- 最初のログインで、マイドライブ直下にスプレッドシート「**会議記録DB**」が作られます。
  - **好きなフォルダに移動して構いません。** 移動してもアプリから使えます。
- 2台目の端末でログインすると、同じスプレッドシートを自動で見つけて使います。
- 画面に戻ってきたときに、自動で最新の内容を読み直します。手動で読み直すときは「再読み込み」を押します。
- ログインは約1時間で切れます。切れたら「再ログイン」ボタンが出るので押してください。

## 5. スプレッドシートの中身

| シート | 列 |
|---|---|
| `meetings`（1行＝1回の会議） | ID / 会議名称 / 実施日 / 参加者（「、」区切り） / 会議記録URL / 登録日時 / 削除 / メモ / 主催者 |
| `series`（1行＝1つの会議名称） | 会議名称 / 概要URL / 作成者 |
| `people`（1行＝1人） | 名前 / 人物メモ / 更新日時 |

- 以前の版で作ったスプレッドシートを使っている場合は、ログイン時に `meetings` の「メモ」「主催者」列、`series` の「作成者」列、`people` シートが自動で追加されます。
- 人物メモは名前の完全一致で結び付けます。表記ゆれ（「田中」と「田中さん」など）があると、別の人として扱われます。

- スプレッドシートを直接編集しても構いません。参加者は「、」で区切ります。
- アプリで削除した会議は、行を消すのではなく「削除」列に印を付けます。この列を空にすると元に戻ります。
- **シート名（`meetings` / `series` / `people`）と1行目の見出しは変えないでください。**
- アプリはスコープ `drive.file` を使うため、**このアプリが作ったファイルにしかアクセスしません**。ほかのドライブのファイルは読みません。そのため、スプレッドシートを手でコピーして作り直したものは使えません。

## 6. 補足

- 登録は行の追記で行うので、PC と iPad で同時に登録しても互いを上書きしません。
- iPad では、ホーム画面に追加した状態より、Safari のタブで開くほうがログインが安定します。
